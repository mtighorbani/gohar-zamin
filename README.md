# فولاد گهرزمین — Corporate Website

Next.js App Router + TypeScript. Incremental, commit-by-commit implementation from the approved design. Stage 01: header and looping organization ticker. Other site sections and routes will be completed in subsequent stages.

```bash
npm install
npm run dev
```

The site is temporarily marked `noindex` until the actual pages are finished. Brand colors are navy, steel gray, and restrained red from the official client logo.
